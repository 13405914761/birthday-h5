# 回忆放映厅 分镜脚本 MEMORY-SHOW-STORYBOARD

> 位置：**age25（照片打印机）之后、Finale 完结页之前**。由 age25 吐出的相纸把观众"带进"放映厅。
> 时长：**30—45 秒**；照片 **10—15 张**；**当前全部用空白拍立得框 + 角标"照片待上传"**，不嵌入真实照片（照片清单见 `memory-show-manifest.example.json`，URL 一律为空）。
> 方法取自参考案例的"时间轴+控件+降级"思路，**不取其蓝色宇宙视觉**；本项目保持奶油白/手账/线条小狗基调。

## 1. 控件与状态机

- **控件**：暂停 / 继续 / 跳过 / 静音（四个真按钮，可 Tab、空格/回车触发）；底部进度条。
- **状态机**：`loading → playing ⇄ paused → skipping → done`；任一张失败进 `error` 占位（见 §4）。
- **音频**：复用 Intro「开启」手势已解锁的 BGM 通道；若仍被浏览器自动播放拦截，自动切**静音播放 + 显示"点按开声"**，不卡死。
- **visibilitychange**：切后台自动 `paused`，回前台不自动续播，等用户点"继续"。
- **返回键**：放映厅期间返回键优先退出放映厅回 age25/Finale 入口，不离开页面。
- **无障碍**：容器 `role="region" aria-label="回忆放映厅"`；切片 `aria-live="polite"` 播报"第几张/共几张"；reduced-motion 下切换只淡入、不推拉。

## 2. 视觉与适配

- 画面：米色纸底 + 一张**空白拍立得框**（白边、底部留手写 caption 区），框内居中大字"照片待上传"，右下角一只线描小狗探头。
- **横竖适配**：拍立得框 `object-fit: contain` 居中；竖图留左右胶带装饰，横图留上下和纸胶带。
- 未来真实照片接入时：`object-fit: cover` + `object-position` 取 manifest 的 `focalX/focalY`，不裁脸。
- **失败占位**：某张加载失败 → 拍立得框内显示"这张没洗出来" + "跳过此张"，继续时间轴，不黑屏。

## 3. 时间轴（12 张示例 · 约 38 秒）

> 实际张数 10—15 可调；每张时长见 manifest `durationSec`。转场词：揭胶带 / 翻页 / 小狗推入 / 小狗挥爪。

| # | 时间点 | 转场进入 | 画面（当前） | 底部 caption（占位文案） |
| --- | --- | --- | --- | --- |
| 1 | 0.0s | 开场：从 age25 吐出的相纸"推入"放映厅 | 空白拍立得居中，小狗探头 | 我们的回忆，从这张开始 |
| 2 | 3.0s | 左侧和纸胶带被"揭起"翻页 | 空白框右滑入 | 第一次一起出门 |
| 3 | 6.5s | 小狗从下推入一张新框，旧框下移出 | 空白框 + 棕狗挥爪 | 你笑起来的样子 |

- **跳过**：任意时点点"跳过" → `skipping`，直接到第 12 张合影并 `done`。
- **暂停/继续**：暂停计时与切片，按钮文案互切。
- **静音**：切 BGM 开关，与全局音频开关同步。

## 4. 降级与失败

- 预取窗口：播到第 i 张时预载 i+1、i+2（当前为空框故几乎瞬时，留作未来真照片）。
- 单张失败：占位卡 + "跳过此张"；连续失败仍能 `done` 进 Finale。
- reduced-motion：转场改 0.2s 淡入，不做"推入/挥爪"位移动画，仅保留框内淡入。

## 5. 交付清单

- [ ] 时长落在 30—45s；张数 10—15。
- [ ] 暂停/继续/跳过/静音可用；后台自动暂停；返回键退放映厅。
- [ ] 横/竖框居中适配；失败占位不卡死。
- [ ] 当前 0 张真实照片，全部空白框 + "照片待上传"；manifest URL 全空。
