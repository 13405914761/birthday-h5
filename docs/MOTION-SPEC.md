# 动态原型动效规格 MOTION-SPEC（线条小狗版 · 可实施规格 · 不含实现代码）

> 配套：`React技术方案.md` §14 / §15.8。本文把 1—25 岁逐页动效落到可执行的设计参数，**不写 React 代码**。
> 动效主路径：**Framer Motion（React 层）+ CSS 变量 / transform / opacity**；手绘描边走 **SVG path `stroke-dashoffset` 画出来**；Lottie 仅限经审核的小型装饰，失败静默降级为静态图。

## 0. 全局规则（先读）

- **触发**：章节吸附进入视口（IntersectionObserver / `whileInView`）才播 `entry`；离屏即停循环，回前台续播。
- **循环频率**：环境 `ambient` 与角色 `character` 循环 **2—4 秒**一个周期，低频舒缓；每章同时循环节点 ≤ 3。
- **执行属性**：只动 `transform` / `opacity`；描边动画在 SVG path 上做。不写 `top/left/width` 动画。
- **按钮召唤**：仅 `locked` 态主按钮有轻微呼吸/光晕；进入 `sheetOpen` 后停止。
- **解锁 `unlock`**：一次性播完即停（不循环），播完切 `unlockedNext`。
- **reduced-motion**：命中 `prefers-reduced-motion` → 直接落终态静态呈现，不播 entry/ambient/character 循环，仅保留弹层必要显现。
- **后台暂停**：`visibilitychange` 切后台暂停全部循环。

## 3. reduced-motion 统一行为

- 上表 `entry/ambient/dog` 循环全部关闭，插画与文字直接以终态静态呈现。
- 保留：主按钮点击 → 弹层淡入（必要显现）、`success` 文案 `aria-live` 播报；不做"开盒/庆祝/抛帽"。
- 放映厅照片切换在 reduced 下用简单淡入，不推拉（见 `MEMORY-SHOW-STORYBOARD.md`）。

## 4. 检查清单

- [ ] 每章循环周期 ∈ [2s, 4s]，同章循环节点 ≤ 3。
- [ ] 离屏/后台循环暂停，不累计定时器。
- [ ] 仅 transform/opacity；描边在 SVG path。
- [ ] Lottie 出现处均有静态降级。
- [ ] reduced-motion 全章落终态。
