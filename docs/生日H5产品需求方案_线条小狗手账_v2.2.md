## 1. 产品目标与用户旅程（更新）

- **情感目标**：翻完 25 岁手账后，进入一段自动放映的「回忆放映厅」，把两人的照片像拍立得一样一张张自动翻出来收尾。
- **新用户旅程**：
```
首屏 → 第1章…第25章（逐页 scroll-snap + 顺序锁 + 按钮开弹层解谜）
     → 第22/23记忆桥
     → 第25章解锁成功
     → 【新增】回忆放映厅（30–45s 自动播放，可暂停/跳过）
     → 终章/回顾（生日快乐 · 23 完成点 · 回看）
```

## 7. 回忆放映厅（本轮新增，独立章）

### 7.1 位置与触发
- 位于 **第 25 章解锁成功之后、终章之前** 的独立全屏章。
- 第 25 章解锁转场结束后自动弹出「要不要看看这些日子」入口；可进入，也可跳过直接终章。

### 7.2 规格（配置驱动）
- 总时长 **30–45 秒**；**10–15 张照片**，每张停留 **2.5–3.5 秒**（由配置 `perPhotoSec` 控制，默认 3s）。
- 形式：拍立得 / 胶片 / 相册纸片**自动播放**；转场含翻页、揭胶带、小狗推照片或挥爪、手绘星与爱心描边。
- 横竖图自适应：横图卡片横放、竖图竖放，统一在奶油底上居中带白边+投影+胶带，不拉伸变形。
- 控制条：**暂停 / 继续 / 跳过 / 静音**（可关放映厅背景音乐）。
- **预加载**：进厅前预载前几张，边播边载后续；加载中显示奶白占位卡。
- **失败占位**：某张图加载失败 → 显示「照片待上传」占位拍立得卡片，不中断放映、不报错。

### 7.3 照片内容
- **照片尚未提供：所有位写「照片待上传」占位，不得虚构任何照片画面。**
- 照片来源与字段见第 8 章上传规范。

## 8. 照片上传规范（本轮新增）

### 8.1 文件要求
| 项 | 规范 |
|---|---|
| 格式 | JPG / PNG / WebP；HEIC 上传时转 JPG |
| 容量 | 单张 ≤ 5 MB |
| 尺寸 | 最长边建议 1600–2400px；过大会压缩 |
| 方向 | 横 / 竖均可，放映厅自动适配 |
| 命名 | `recall_001.jpg`、`recall_002.jpg` …（三位序号，即放映顺序） |
| 数量 | 10–15 张 |

### 8.2 元数据 schema（每照片一条，示例为空值）
```json
{
  "file": "recall_001.jpg",
  "order": 1,
  "alt": "",
  "capture_time": "",
  "memory_note": "",
  "focal": { "x": 0.5, "y": 0.5 },
  "orientation": ""
}
```
- `alt`：无障碍替代文字（写给读屏）。
- `capture_time`：拍摄时间（如 2026-05）。
- `memory_note`：一句回忆（≤30 字）。
- `focal`：裁剪焦点归一化坐标（0–1），横图裁切时保人不保边。
- `orientation`：`landscape` / `portrait`。

### 8.3 隐私与本地处理
- 照片与元数据仅**本地打包进 H5 / 本地播放**，不上传服务器、不做云端统计；放映厅音乐可静音。
